## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的数据管道通过迭代器逐条消费，用户取消后要么停不下来，要么把连接和临时文件泄漏了。请从零实现一个可取消的流式迭代器组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持多级迭代器串联（源到过滤到转换），取消要能沿链路传播到源头；2) 取消语义：取消后调用 hasNext 或 next 必须返回明确的取消结果，不得静默返回空数据；3) 资源释放：取消或正常结束后必须按注册的逆序释放资源，释放失败要记录并继续；4) 幂等取消：多次取消不得重复释放资源或抛异常；5) 支持超时取消：迭代过程中整体超过时间预算要自动取消并说明卡在哪一级；6) 支持部分结果保留：取消前已产出的数据必须仍可被调用方拿到；7) 提供统计：已产出条数、各级调用次数、取消来源与释放的资源数；8) 测试覆盖取消传播、资源释放顺序、幂等取消、超时取消、部分结果保留与统计；`mvn -q verify` 一条命令跑通。
